# 胖东来 · 门店临期/食品安全自查助手

面向胖东来零售场景的最小可用应用 demo：把「商品保质期知识库 + 临期分级判定规则」封装成可复用工具，输入当日商品清单，一键生成食品安全巡检清单。

## 为什么做这个

胖东来的口碑建立在极致的商品与服务品质上，食品安全与临期管理是门店每天的高频刚需。这个 demo 演示的是：如何把一个"靠老师傅经验和人工盘点"的环节，变成可复制、可追溯的数字化工具。

## 功能

- **商品知识库**（`products.json`）：20 类商品的默认保质期与贮存条件要求，可扩展。
- **临期分级判定**：按保质期长短采用行业通用阈值，自动判定「过期 / 临期 / 正常」。
- **处理建议**：过期 → 下架报损；临期 → 打折促销专区售卖；正常 → 正常销售。
- **巡检清单生成**：读入 CSV 商品清单，输出 Markdown 巡检清单（含到期日、剩余天数、贮存合规对照）。

## 运行

```bash
python expiry_checker.py --date 2026-10-17
```

可选参数：

- `--csv` 指定商品清单（默认 `demo_products.csv`）
- `--date` 指定巡检日期（默认今天）

Windows 下可双击 `run.bat`。

## 技术栈

Python（argparse / datetime / csv / json）· 规则引擎 + 可扩展 JSON 知识库 · Markdown 报告生成

- **需求调研**：食品安全与临期管理的业务规则梳理
- **数据建设**：商品保质期知识库（结构化、可追溯）
- **工具开发**：把规则封装为可复用的命令行工具
- **效果验证**：输出可复盘、可审计的巡检清单台账
